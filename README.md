# 🐾 PetPlay - Sistema de Gerenciamento de Pets

## 📋 Sobre o Projeto
Sistema desenvolvido em Python para gerenciamento de pets, permitindo
cadastrar, consultar e modificar informações de animais de estimação.

## 🚀 Funcionalidades
- ✅ Cadastrar pets com nome, idade e peso
- ✅ Exibir informações de todos os pets
- ✅ Buscar pet por nome, peso ou idade
- ✅ Modificar dados cadastrados
- ✅ Validação de dados em todas as entradas

## 🛠️ Tecnologias
- Python 3.x

## 📚 Conceitos Aplicados
- Programação Orientada a Objetos (POO)
- Encapsulamento com getters e setters
- Métodos estáticos com @staticmethod
- Tratamento de erros com try/except
- Validação de dados
